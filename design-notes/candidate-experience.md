# Candidate Experience (CX)

The candidate is the primary beneficiary of fairness. Everything flows from that.

## 1. Candidate Onboarding

The system should feel like:
- 	“Finally, someone is on my side.”
- 	“This is not a job board.”
- 	“This is not a recruiter.”
- 	“This is a matching engine that works for me.”

### 1.1. Profile Creation

Candidates provide:
- 	skills (self declared)
- 	experience (structured)
- 	preferences (salary, location, remote, culture)
- 	constraints (visa, schedule, disability accommodations)
- 	optional demographic data (for bias monitoring only)

### 1.2. AI Assisted Structuring

The system:
- 	parses their CV
- 	infers skills
- 	identifies transferable skills
- 	highlights gaps
- 	asks for confirmation

The candidate is always in control.

### 1.3. Visibility Controls

Candidates choose:
- 	who can see them
- 	what data is visible
- 	whether they want to be anonymous until a match is confirmed

This is a candidate first system.

## 2. Matching Experience

This is where fairness becomes tangible.

### 2.1. Transparent Matches

Each match includes:
- 	why they were matched
- 	which skills mattered
- 	which inferred skills helped
- 	which constraints aligned
- 	what the company is actually looking for

### 2.2. No Ghosting

The system guarantees:
- 	every match leads to a response
- 	every rejection includes an explanation
- 	candidates never disappear into a void

### 2.3. Candidate Agency

Candidates can:
- 	accept or decline matches
- 	request clarification
- 	challenge incorrect inferences
- 	hide roles they don’t want

## 3. Feedback & Growth

This is where the system becomes transformative.

### 3.1. Skill Gap Insights

The system tells candidates:
- 	which skills would unlock more matches
- 	which skills are emerging in their field
- 	which skills they already have but haven’t articulated

### 3.2. Career Path Suggestions

Based on their profile, the system can suggest:
- 	adjacent roles
- 	alternative industries
- 	seniority paths

### 3.3. Bias Monitoring

Candidates can see:
- 	whether they are being unfairly filtered
- 	whether certain companies consistently reject similar profiles
- 	whether the system is correcting for bias

*This is radical transparency.*
