# Fair Hiring Protocol — Overview

The Fair Hiring Protocol (FHP) is an open, community governed standard for fair, transparent, and bias aware hiring.  
It defines the schemas, processes, fairness rules, and governance structures required to build hiring systems that treat candidates with dignity and companies with clarity.

**FHP is not a product.**

It is a **protocol layer** — a public good — designed to fix what is structurally broken in hiring.

---

## 1. Goals

- Replace opaque, biased hiring systems with transparent, auditable ones  
- Evaluate candidates based on skills and evidence, not pedigree  
- Detect and correct systemic bias  
- Provide clear, structured explanations for every decision  
- Protect candidate rights  
- Hold companies accountable  
- Enable interoperable, open source hiring tools  

---

## 2. Core Components

### 2.1 Canonical Schemas
- Candidate Profile  
- Job Brief  
- Match Explanation  
- Skill Ontology  

### 2.2 Matching Pipeline
A deterministic, auditable process:
1. Normalization  
2. Semantic Expansion  
3. Constraint Satisfaction  
4. Skill Scoring  
5. Transferable Skill Compensation  
6. Preference Alignment  
7. Bias Detection & Correction  
8. Explanation Generation  

### 2.3 Fairness Framework
- Conditional parity  
- Bias detection thresholds  
- Correction factors  
- Drift monitoring  

### 2.4 Governance
- Protocol Council  
- Technical Working Group  
- Fairness Oversight Board  
- Public proposals (FHP P)  
- Transparent voting  

---

## 3. Design Principles

- **Fairness first**  
- **Transparency over convenience**  
- **Candidate dignity**  
- **Bias aware, not bias blind**  
- **Open governance**  
- **Model agnostic**  
- **Stable and versioned**  

---
