# Contributing to the Fair Hiring Protocol (FHP)

Thank you for your interest in contributing to the Fair Hiring Protocol.  
FHP is a public, open, community governed standard designed to make hiring fair, transparent, and bias aware.

We welcome contributions from:
- engineers
- fairness researchers
- employment law experts
- candidates
- employers 
- open source contributors

This document explains how to contribute effectively and responsibly.

---

## 1. Guiding Principles

All contributions must align with the core values of FHP:

- **Fairness first**
- **Transparency over convenience**
- **Candidate dignity**
- **Bias awareness, not bias blindness**
- **Open governance**
- **No corporate capture**
- **Stability and backwards compatibility**

---

## 2. Ways to Contribute

### 2.1 Propose a Change (FHP P)
All changes to the protocol, schemas, scoring logic, ontology, or governance must be submitted as a proposal.

Create a new file in `/proposals` using the template: `proposals/FHP-P-YYYY-NNN-title.md`


### 2.2 Improve Documentation
You may submit PRs to improve clarity, examples, diagrams, or onboarding docs.

### 2.3 Contribute to the Reference Implementation
The `/reference-impl` directory contains a minimal implementation of the protocol.
Contributions must not alter fairness logic.

### 2.4 Contribute to the Ontology
Skill mappings and semantic relationships live in `/ontology`.
Changes must be evidence based and reviewed by the Technical Working Group.

---

## 3. Contribution Workflow

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request
5. Participate in public review
6. Await Protocol Council decision

All discussions are public.

---

## 4. Code of Conduct

All contributors must follow `CODE_OF_CONDUCT.md`.
Harassment, discrimination, or attempts to undermine fairness will not be tolerated.

---

## 5. Licensing

All contributions are made under the project’s open-source license.
By contributing, you agree that your work becomes part of the public standard.

---

## 6. Questions?

Open an issue or join the discussion.

We’re building this together.
